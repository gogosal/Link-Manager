# 🚀 Cyberpunk Link Manager

A futuristic link manager with a cyberpunk aesthetic for organizing your bookmarks and connections.

## ✨ Features

- **Cyberpunk Theme** - Neon colors, glitch effects, and futuristic design
- **Section Organization** - Organize links into custom sectors/categories
- **Visual Previews** - Add custom images to your links
- **Drag & Drop** - Reorder links and sections easily
- **Local Storage** - All data saved locally in your browser
- **Responsive Design** - Works on desktop and mobile devices

## 🎮 Quick Start

1. Open `index.html` in your browser
2. Click **"+"** to add your first connection
3. Create custom sectors using **"NEW SECTOR"**
4. Drag and drop to reorganize

## 🛠️ Tech Stack

- **HTML5** - Semantic structure
- **CSS3** - Cyberpunk styling with animations
- **Vanilla JavaScript** - Modular ES6+ code
- **Local Storage** - Client-side data persistence

## 🌟 Usage

- **Add Links**: Click the **+** button or press `Ctrl+N`
- **Edit Links**: Click the ✏️ button on any card
- **Delete Links**: Click the 🗑️ button on any card
- **Manage Sectors**: Use sidebar buttons to add/remove sections
- **Navigate**: Click sector names to filter links
